KslLoader

actual object KslLoader(source)

Android: libksl.so ships in the AAR's jniLibs; the system loader handles extraction (minSdk 24 needs no ReLinker). One attempt per process, its outcome kept (see availability).

expect object KslLoader(source)

Loads the native library once per process and checks the ABI. availability answers without throwing whether the library can be used; ensureLoaded throws KslException when it cannot.

actual object KslLoader(source)

Loads libksl on the JVM: an explicit path (-Dkuicksilver.native.path), otherwise the jar resource extracted into an owner-only directory and checked against the SHA-256 manifest; -Dkuicksilver.native.system=true falls back to System.loadLibrary("ksl"). The ABI is checked right after loading. One attempt per process, its outcome kept (see availability). The library is never unloaded.

actual object KslLoader(source)

Kotlin/Native links ksl and OpenSSL statically into the binary: loading is initialization plus the ABI check. The first outcome is published once and kept; threads racing on the first call may each run the idempotent ksl_init, but all of them see the same outcome.

Whether libksl can be used in this process; never throws (except for fatal VM errors such as OutOfMemoryError). Thread-safe: every caller sees the same outcome (on the JVM and Android concurrent first calls wait for the one attempt).

actual fun ensureLoaded()

Loads and initializes libksl unless this process already tried, then checks its ksl ABI version. The TLS layer calls it before its first native call; an application may call it at startup to fail fast on a missing or tampered library (threat model, supply chain). Thread-safe and cheap after the first attempt. A failure throws KslException (KslException.NativeLoad, KslException.AbiMismatch, or on system-OpenSSL builds KslException.Version and KslException.MissingSymbol). The outcome of the first attempt is kept for the life of the process, shared with availability: after a failure every later call throws the same exception instance without loading again (a fixed installation needs a restart). The library is never unloaded.
