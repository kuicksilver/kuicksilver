availability

actual fun availability(): NativeAvailability(source)

Whether libksl can be used in this process; never throws (except for fatal VM errors such as OutOfMemoryError). Performs the same single load attempt as ensureLoaded (whichever is called first loads, the other reuses the outcome) and keeps the outcome for the life of the process, both NativeAvailability.Available and NativeAvailability.Unavailable: a later call never retries. Thread-safe: every caller sees the same outcome (on the JVM and Android concurrent first calls wait for the one attempt).

Use it at startup when the application must also run where Kuicksilver ships no native build (another OS or CPU architecture), to choose a fallback transport instead of catching KslException: if (!KslLoader.isAvailable()) fallBackToTcp(). On Kotlin/Native the library is linked statically, so the answer is NativeAvailability.Available unless initialization or the ABI check fails.
