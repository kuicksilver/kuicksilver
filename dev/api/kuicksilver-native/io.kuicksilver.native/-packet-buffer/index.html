PacketBuffer

expect class PacketBuffer : AutoCloseable(source)

Off-heap packet memory handed to ksl by address: a direct ByteBuffer on the JVM, native heap on Kotlin/Native. Not thread-safe; one owner at a time. close releases the memory; use after close throws IllegalStateException.
