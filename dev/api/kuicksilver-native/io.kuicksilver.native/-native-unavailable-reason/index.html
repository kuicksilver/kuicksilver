NoLibraryForPlatform

No library is shipped for this platform: on the JVM, no jar resource for the host classifier (e.g. freebsd-x86_64) and neither -Dkuicksilver.native.path nor -Dkuicksilver.native.system=true; on Android, no libksl.so for the device's CPU ABI in the APK. The expected case for a fallback transport.

Link copied to clipboard
LoadFailed

A library was found or named but could not be loaded or initialized: System.load/System.loadLibrary failed (a missing dependency, a noexec work directory, a wrong architecture), the file named by -Dkuicksilver.native.path does not exist, ksl_init failed, or a system OpenSSL is unsupported (KslException.Version, KslException.MissingSymbol).

IntegrityMismatch

The jar resource failed the SHA-256 manifest check (a tampered or corrupted artifact, a missing manifest or entry, or several differing copies on the classpath) and was not loaded. Usually worth reporting rather than silently ignoring.

AbiMismatch
