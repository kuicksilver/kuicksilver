InMemoryAltSvcStore

class InMemoryAltSvcStore : AltSvcStore(source)

The default AltSvcStore: in memory, thread-safe enough for one engine (all calls happen under the engine's lock). It keeps at most 1000 origins; the least recently used go first (threat-model 3.18).

networkId
Link copied to clipboard
open override var networkId: String?

The network (Http3ClientConfig.networkId) the stored entries were learned on, as the engine last set it; null when not known. A store kept across restarts keeps it with the entries: at its first request the engine compares it with the current network and, when they differ, drops the entries without persist=1 (RFC 7838 section 2.2: "clients SHOULD remove from cache all alternative services that lack the "persist" flag with the value "1" when they detect such a change"). The default keeps nothing and answers null, which never matches a network the engine knows: an application's store that does not implement it loses its non-persistent entries at each start where the engine knows the network. Used with Http3ClientConfig.networkId only: the networks connectionMigration follows have no identity that survives a restart (Http3ConnectionMigration.networks) and are never stored.

Forgets every entry of every origin, persistent ones included: the engine's clearAlternativeServices without an origin, so alternative service information goes when origin-specific data is cleared (RFC 7838 section 9.4: it "MUST be removed when origin-specific data is cleared").
