Refused

The server closed the connection during setup without a TLS alert, or version negotiation failed. CONNECTION_REFUSED (a server in Drain, stopping, or with a full accept queue: RFC 9000 section 5.2.2), at the first Initial or on a connection whose handshake completed into a full accept queue, is transient: the call falls back to HTTP/1.1 once, the alternative is not marked broken and the next call tries HTTP/3 again. Any other code marks the alternative broken.

H2Refused

The call went over HTTP/1.1 because the server answered HTTP/2 with HTTP_1_1_REQUIRED (RFC 9113 section 7), on this call (repeated over HTTP/1.1, when that was safe: otherwise the call failed with Http11RequiredException) or lately (its route offers only http/1.1 for 5 minutes, doubling up to 2 days at each new refusal). The reason HTTP/3 was not used is in the log line as h3Fallback=.
