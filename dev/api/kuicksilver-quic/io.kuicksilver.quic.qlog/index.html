class AsyncQlogSink(delegate: QlogSink, val queueCapacity: Int = 8192, val sampleEvery: Int = 1, dispatcher: CoroutineDispatcher = Dispatchers.IO.limitedParallelism(1)) : QlogSink, AutoCloseable

A QlogSink that never blocks the endpoint loop (docs/guide/quic.md, "qlog"): delegate's open, write and close run on dispatcher, one at a time, while the loop only queues them. The queue holds at most queueCapacity records over all connections; a record that finds it full is dropped and counted in dropped, so a slow disk loses trace lines, never throughput. Opening and closing a trace are never dropped (one each per traced connection).

qlogDirectory
Link copied to clipboard
fun qlogDirectory(context: Context, name: String = "kuicksilver-qlog"): DirectoryQlogSink

Android: a DirectoryQlogSink writing into the directory name inside the app's cache directory (Context.cacheDir), which only the app can read, is left out of Auto Backup, and is the first place the system reclaims when storage runs low. The directory is created now, owner-only (0700), and checked as DirectoryQlogSink checks it; read the traces with adb shell run-as <package> ls cache/<name> (debuggable builds) or from the app. Works in release builds too: a trace holds no keys. Below API 26 (no java.nio.file, so the directory cannot be checked) it throws IllegalArgumentException, as DirectoryQlogSink refuses there.
