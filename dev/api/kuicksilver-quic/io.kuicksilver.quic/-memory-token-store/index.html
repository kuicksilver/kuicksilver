MemoryTokenStore

class MemoryTokenStore(val maxServers: Int = 256, val tokensPerServer: Int = 4) : QuicTokenStore(source)

A QuicTokenStore in memory, bounded to maxServers keys of tokensPerServer tokens each: the newest token is taken first, the oldest one beyond tokensPerServer is dropped, and the server not used for longest is evicted beyond maxServers (as quic-go's NewLRUTokenStore). Safe to share between endpoints; its contents end with the process.
