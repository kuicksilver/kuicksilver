Cubic
Link copied to clipboard
class Cubic(maxDatagramSize: Int = 1200, hystart: Boolean = true) : CongestionController

CUBIC congestion control (RFC 9438) with HyStart++ (RFC 9406), the default controller. Byte arithmetic throughout: C = 0.4, beta = 0.7, fast convergence, and the Reno-friendly region (alpha = 3(1 - beta)/(1 + beta)) so a short-RTT flow never grows slower than Reno. The initial slow start ends by HyStart++ (an RTT increase enters Conservative Slow Start, five CSS rounds end slow start, an RTT drop returns to slow start) or by the first congestion event; a later slow start (after persistent congestion) is plain slow start up to the ssthresh the loss set (RFC 9406 section 4.3). Pacing and the send quantum are those of NewReno. Nothing here allocates after construction.

PreferredAddress
Link copied to clipboard
class PreferredAddress

A server's preferred address (RFC 9000 sections 9.6 and 18.2): where it asks clients to move after the handshake, one address per family it offers. Each is bound literally (no NAT indirection: the address advertised is the address the socket binds), must differ from the endpoint's own address, and may not use a reflection port (53, 123, 1900, 5353, 11211). The endpoint opens a socket on each (with every loop of a group sharing the port, as for the main socket) and advertises them with its sequence-1 connection ID. A client moves only to the address of the family it already uses, only after it validated the path, and only from a server whose own address is public when the preferred one is local (threat-model 3.14).

QuicLbNonceReservation
Link copied to clipboard
interface QuicLbNonceReservation

Keeps the nonce counter of one QUIC-LB nonce space across process restarts, so no restart reuses a nonce (draft-ietf-quic-load-balancers-21 section 9.6). With it, the nonce sequence is fixed (derived from the configuration key, or in clear from secret), and the endpoint reserves nonces in blocks of BLOCK: it uses nonces only below the mark it stored last, and stores the end of the next block once half of the current one is drawn; a new process starts at load. A crash skips the rest of a block, never reuses one. Every process that uses the nonce space must share the store (one file per key, say), and only one process may use it at a time.

defaultNetworks
Link copied to clipboard
fun ConnectivityManager.defaultNetworks(): Flow<Network?>

The device's default network (ConnectivityManager.registerDefaultNetworkCallback, API 24) as a NetworkMigrator source: the current default first, then each new one, null while there is none. All collectors of one manager share a single callback (Android allows about 100 per app, so one per connection would run out in a large pool); it is registered with the first collector and unregistered when the last one stops. When registering throws (TooManyRequestsException), every current collection ends with that exception and the next collection tries again; a NetworkMigrator reports it as MigrationEvent.SourceFailed. Needs ACCESS_NETWORK_STATE, which the library manifest declares.

Binds local to interface interfaceIndex (iOS, macOS; an NwPathKey.interfaceIndex or if_nametoindex): every datagram of the socket leaves through that interface whatever the default route is (IP_BOUND_IF; IPV6_BOUND_IF on an IPv6 socket, which a wildcard address opens dual-stack), so a connection can move to a network before the system prefers it.
