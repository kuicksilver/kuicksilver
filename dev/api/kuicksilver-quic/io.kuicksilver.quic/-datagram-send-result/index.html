object Sent : DatagramSendResult

The datagram is queued for the loop; whether it arrives stays unknown, since datagrams are never retransmitted (RFC 9221 section 5).

TooLarge
Link copied to clipboard
class TooLarge(val max: Int) : DatagramSendResult

The payload exceeds what the peer's limit and the path allow at the call (QuicConnection.maxDatagramSize). max is the largest payload that fits, 0 also when none fits; a TooLarge for an empty payload means not even an empty datagram fits (e.g. a peer max_datagram_frame_size of 1). Machine-readable: peerSupportsDatagrams && maxDatagramSize.value == 0.
