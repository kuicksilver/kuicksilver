ConnectionAttempt

class ConnectionAttempt(source)

What the endpoint knows about a new client when it asks ConnectionAdmission.admit (docs/guide/quic.md, "Admission and endpoint limits").

The endpoint builds one per queued Initial that passed the cheap checks (1200 bytes, a supported version, a DCID of at least 8 bytes, no reflective source port) and the hard limits (maxConnections, acceptQueue, maxConnectionsPerIp); the policy never sees datagrams those checks dropped or refused.

val addressValidated: Boolean

True when the Initial carried a Retry token or a NEW_TOKEN token this endpoint minted for this address (RFC 9000 sections 8.1.2 and 8.1.3). A AdmissionDecision.Retry for an attempt that answered a Retry is a contract violation and is dropped; one for a NEW_TOKEN holder is sent (the client then shows the Retry token instead).
