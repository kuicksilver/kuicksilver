IoCapabilities

class IoCapabilities(val ecnSend: Boolean, val ecnReceive: Boolean, val gsoMaxSegments: Int, val gro: Boolean, val df: Boolean, val batch: Int)(source)

What a DatagramIo can do (ADR-0006); the portable implementations report none of the accelerated features except, on the JVM, ecnSend through IP_TOS.
