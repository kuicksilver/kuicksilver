ConnectionCore

class ConnectionCore(source)

The sans-IO state machine of one QUIC connection (ADR-0004): datagrams in through handleDatagram, datagrams out through poll, time through nextTimeout/onTimeout, everything else through nextEvent. Never touches a socket, a clock or a coroutine.

This class owns the state and the public API; the internal transitions are extension functions in core/: ConnectionCore.handshake.kt, ConnectionCore.paths.kt, ConnectionCore.close.kt and ConnectionCore.timers.kt.

maxDatagramPayload
Link copied to clipboard
val maxDatagramPayload: Int

Largest DATAGRAM payload the peer accepts in one of our packets (RFC 9221 section 3), the smaller of two bounds: the payload whose whole frame (type, Length, payload) fits the peer's max_datagram_frame_size, and the payload of a frame filling a packet (MTU minus short header and tag) less 32 bytes kept for a short ACK beside it. The reserve only shrinks the packet's bound: a small peer limit is support for small datagrams, not none. 0 when the peer did not advertise support, and when its limit leaves room for an empty datagram only (2) or for no frame with a Length field at all (1).
