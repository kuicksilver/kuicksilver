NwPathKey

class NwPathKey(val interfaceIndex: Int, val interfaceType: NwInterfaceType, val interfaceName: String)(source)

The network a satisfied default path runs over, as nwPathUpdates reports it: the path's preferred interface, the first one nw_path_enumerate_interfaces lists (the order of preference, as NWPath.availableInterfaces). Two keys are equal when interfaceIndex and interfaceType are, which makes it the N of a NetworkMigrator: a change of key is a change of network, a path update that keeps the interface (a new address, a DNS change) is not.
