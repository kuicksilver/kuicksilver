ConnectionListener

interface ConnectionListener(source)

Hears the lifecycle of every connection of an endpoint (docs/guide/quic.md, "Observability"), set with QuicEndpointConfig.listener. Each connection reports onOpened first and onClosed last, exactly once each.

Every callback runs on the endpoint loop that owns the connection, in the order the events happened: it must return quickly and must not block or suspend (hand the work to your own coroutine when it is more than counting or logging). An exception out of a callback is logged at LogLevel.Warn and counted, never the connection's failure.
