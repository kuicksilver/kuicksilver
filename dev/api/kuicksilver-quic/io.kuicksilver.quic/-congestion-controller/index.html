CongestionController

@SubclassOptInRequired(markerClass = [ExperimentalKuicksilverApi::class])
interface CongestionController(source)

Congestion control of one path (RFC 9002 section 7). The core calls these from its single-threaded loop; a controller never blocks and never allocates on the hot path. Cubic with HyStart++ is the default; NewReno and the experimental Bbr are choices.
