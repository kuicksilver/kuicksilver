EndpointStats

class EndpointStats(source)

A snapshot of an endpoint's stateless work, admission outcomes and connection lifecycle; every counter counts since the endpoint started. QuicEndpoint.stats sums it over every loop of the endpoint (docs/guide/quic.md, "Observability"). The loops keep plain counters, so taking a snapshot allocates this object only and costs nothing per packet; values are read without a lock and may lag the loops by a few events.
