fun localAddress(i: Int): InetSocketAddress?

Our address of slot i (RFC 9000 section 9: a path is the 4-tuple). For a received datagram, the address it was sent to, which a socket bound to a wildcard address learns from IP_PKTINFO / IPV6_PKTINFO (the accelerated socket; null when the socket cannot tell, as the portable ones). For an outgoing one, the source it must leave from, null for the socket's own choice. Set it after setAddress, which clears it.
