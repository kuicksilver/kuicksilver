Cubic

class Cubic(maxDatagramSize: Int = 1200, hystart: Boolean = true) : CongestionController(source)

CUBIC congestion control (RFC 9438) with HyStart++ (RFC 9406), the default controller. Byte arithmetic throughout: C = 0.4, beta = 0.7, fast convergence, and the Reno-friendly region (alpha = 3(1 - beta)/(1 + beta)) so a short-RTT flow never grows slower than Reno. The initial slow start ends by HyStart++ (an RTT increase enters Conservative Slow Start, five CSS rounds end slow start, an RTT drop returns to slow start) or by the first congestion event; a later slow start (after persistent congestion) is plain slow start up to the ssthresh the loss set (RFC 9406 section 4.3). Pacing and the send quantum are those of NewReno. Nothing here allocates after construction.
