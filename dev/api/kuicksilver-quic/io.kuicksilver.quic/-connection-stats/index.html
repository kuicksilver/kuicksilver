ConnectionStats

class ConnectionStats(source)

A snapshot of the connection's recovery and path state (docs/architecture.md, "Cross-Cutting Concerns"). Counters run since the connection started; RTT, window and MTU values belong to the active path. QuicConnection.stats builds it from any thread while the endpoint loop goes on updating the connection, without a lock: each field is a value the loop held, but two fields need not come from the same instant (bytesSent may already count a packet that packetsSent does not).

val datagramsDroppedSocket: Long

UDP datagrams of this connection the socket did not take: a send that failed (a filter, an unreachable route) or took only part of a batch (a full send buffer). Loss recovery repairs them; a steady rise means the socket is the bottleneck. It may over-count when the socket fails mid-batch: a send that throws counts its whole batch, although the slots before the failing one may have left.
