open fun disableEcnMarking()

ECN validation failed on a path that sends through this socket (RFC 9000 section 13.4.2). A socket that marks per socket, like the portable one, clears IP_TOS: every connection on it stops marking. A socket that marks per datagram ignores it: the core already sends NotEct on the failed path, and the other connections keep validating ECN.

send
Link copied to clipboard
abstract suspend fun send(batch: PacketBatch): Int

Sends the slots of batch in order; returns how many left. A result below batch.count means the socket refused the rest (a full send buffer): the endpoint counts them in ConnectionStats.datagramsDroppedSocket and loss recovery repairs them. A send that throws is counted as losing the whole batch, so an implementation that can should return the slots it sent before a failure instead of throwing.
