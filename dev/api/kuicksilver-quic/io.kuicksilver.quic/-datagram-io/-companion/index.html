suspend fun DatagramIo.Companion.open(local: InetSocketAddress, network: Network, prefer: IoPreference = IoPreference.Accelerated): DatagramIo

Binds local on network (Android): every datagram of the socket leaves through that network whatever the default network is (Network.bindSocket), so a connection can move to a network before the system switches to it. The accelerated transport when prefer asks for it and the device has it, the portable one otherwise; throws the IOException of bindSocket when the network is gone, the socket closed.

suspend fun DatagramIo.Companion.open(local: InetSocketAddress, interfaceIndex: Int, prefer: IoPreference = IoPreference.Accelerated): DatagramIo

Binds local to interface interfaceIndex (iOS, macOS; an NwPathKey.interfaceIndex or if_nametoindex): every datagram of the socket leaves through that interface whatever the default route is (IP_BOUND_IF; IPV6_BOUND_IF on an IPv6 socket, which a wildcard address opens dual-stack), so a connection can move to a network before the system prefers it. The accelerated transport when prefer asks for it; the portable socket cannot be bound to an interface, so when the accelerated one is refused (or prefer is IoPreference.Portable) the socket is unbound and follows the default route. Throws IOException when the system refuses the binding (an index that names no interface); the socket is closed then.
