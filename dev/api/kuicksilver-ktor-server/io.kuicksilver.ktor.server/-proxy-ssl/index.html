ProxySsl

class ProxySsl(source)

The PP2_TYPE_SSL TLV of a version 2 header: how the client reached the proxy over TLS, as the proxy reports it. This is the proxy's word, not a TLS session of this server: it is trusted as far as the proxy is (ProxyProtocolConfig).
