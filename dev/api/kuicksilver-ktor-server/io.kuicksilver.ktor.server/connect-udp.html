connectUdp

fun Route.connectUdp(proxy: UdpProxy = UdpProxy()): Route(source)

Serves CONNECT-UDP (RFC 9298) with proxy on an engine with connectUdp = true: an Extended CONNECT over HTTP/3 whose :protocol is connect-udp, at any path (the proxy matches its own pathTemplate and answers 404 for another). Nothing else matches the route: HTTP/1.1 and HTTP/2 requests and other CONNECTs go on to the routes that follow; a CONNECT-UDP request no route takes gets Ktor's 404, and one another route answers with a 2xx gets 501 (no tunnel was opened). Put it inside an authenticate { } block or behind your own check: "HTTP servers that support UDP proxying ought to restrict its use to authenticated users" (RFC 9298 section 7); a refusal there (401, 407) goes out as it is. The proxy answers and relays the tunnel (UdpProxy.serve); the call ends with the tunnel.

proxy holds the target filter (UdpTargetFilter.PublicOnly by default) and the limits, shared by every tunnel the route serves: one UdpProxy per route, not per request.
