KuicksilverPlainConnector

class KuicksilverPlainConnector : EngineConnectorConfig(source)

A plain HTTP/1.1 connector, as Ktor's connector { }, with trustedGateway and, opt-in, cleartext HTTP/2 (h2c): made by plainConnector { ... } in the engine configuration. A plain connection is secured by no certificate, so a request whose target is an https URI (absolute form, or :scheme https over h2c) gets 421 Misdirected Request (RFC 9110 section 7.4) unless trustedGateway is set.
