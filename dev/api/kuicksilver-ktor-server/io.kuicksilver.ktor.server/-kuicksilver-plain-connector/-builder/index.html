h2c

var h2c: H2cMode

HTTP/2 over cleartext TCP with prior knowledge (RFC 9113 section 3.3), H2cMode.Off by default: H2cMode.WithHttp11 serves HTTP/1.1 and h2c on this port, told apart by the client connection preface; H2cMode.Only serves h2c alone. Independent of the engine's http2 (which is ALPN h2 on TLS connectors). The engine's http2Settings, limits, flood defences and webSocketsOverHttp2 (RFC 8441, ws:// over h2c) apply as on TLS. Cleartext: only behind a trusted network or proxy (CWE-319; docs/spec/threat-model.md). A connector that the engine turns into a TLS one (the configuration's identity, EngineMain's kuicksilver.tls.* files) cannot take it: the start fails with IllegalArgumentException, since HTTP/2 over TLS "MUST use protocol negotiation in TLS" (section 3.3).

The PROXY protocol (HAProxy, versions 1 and 2) on this connector: every connection must start with a header from one of its trusted sources, which becomes the requests' origin; null (the default) takes none. See ProxyProtocolConfig.

trustedGateway
Link copied to clipboard
var trustedGateway: Boolean

False by default: a request whose target is in absolute form with the https scheme (GET https://host/ HTTP/1.1) is answered 421 Misdirected Request and never reaches the application, since a request for an "https" resource "MUST be rejected unless it has been received over a connection that has been secured via a certificate valid for that target URI's origin" (RFC 9110 section 7.4). Origin-form requests, which a gateway in front of the server sends, are served whatever their Host. True accepts such targets: only when every client of this connector is a trusted gateway ("Unless the connection is from a trusted gateway").
