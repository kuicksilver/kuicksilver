ProxyHeader

class ProxyHeader(source)

The PROXY protocol header a connection began with (ProxyProtocolConfig). ProxyHeader.sourceAddress and ProxyHeader.destinationAddress are the client's address and the one it connected to on the proxy: IP literals (a dotted quad, or IPv6 as RFC 5952 recommends) for ProxyFamily.Inet and ProxyFamily.Inet6, the socket path for ProxyFamily.Unix (an abstract one as @ and its name), null for a ProxyCommand.Local header and for ProxyFamily.Unspecified. The ports are null where the family has none.
