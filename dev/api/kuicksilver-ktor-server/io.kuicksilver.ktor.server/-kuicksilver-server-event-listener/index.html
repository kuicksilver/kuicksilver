KuicksilverServerEventListener

abstract class KuicksilverServerEventListener(source)

Hears the server engine's connections and requests over HTTP/1.1, HTTP/2 and HTTP/3 (docs/guide/ktor.md, "Observability"); set it with eventListener in the engine configuration. Every method has an empty default. A connection reports connectionOpened once its TLS handshake (HTTP/1.1, HTTP/2) or QUIC handshake (HTTP/3) completed, and connectionClosed when the engine is done with it; each request reports requestStarted before the application's pipeline and requestEnded after it.

Callbacks run on the engine's coroutines and must return quickly; an exception out of one (a CancellationException included) is logged as a warning on the application's log and otherwise ignored.

connectionRefused
Link copied to clipboard
open fun connectionRefused(protocol: HttpProtocolVersion, remote: InetSocketAddress?, reason: String)

A client from remote was refused before it became a connection, for reason. For TCP the refusal comes right after accept, before the TLS handshake, so whether the client would have spoken HTTP/1.1 or HTTP/2 is not known and protocol is HTTP_1_1; the socket is closed at once. Reasons: per-IP limit (the address holds maxTcpConnectionsPerIp connections already), HTTP/2 repeat offender (the address serves an http2RepeatOffenderPenalty; on a PROXY protocol connector, the client its header names, while remote stays the TCP peer, the proxy), PROXY protocol untrusted source (a PROXY protocol connector's peer outside its trustedSources) and PROXY protocol header (no valid PROXY protocol header within its limits; reported after the header was read, so remote is the TCP peer). A connector at maxTcpConnections refuses no one: it stops accepting and the OS backlog holds new clients, so they are not reported here.
