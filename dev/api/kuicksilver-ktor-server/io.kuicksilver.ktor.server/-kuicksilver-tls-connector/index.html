KuicksilverTlsConnector

class KuicksilverTlsConnector : EngineConnectorConfig(source)

A TLS connector on every platform: HTTP/1.1 over TLS on TCP and, unless turned off, HTTP/3 on UDP on the same port. clientAuth Optional asks for a client certificate without requiring one; trust verifies it.
