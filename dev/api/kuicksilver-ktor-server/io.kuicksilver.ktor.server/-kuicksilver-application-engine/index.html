KuicksilverApplicationEngine

class KuicksilverApplicationEngine(environment: ApplicationEnvironment, monitor: Events, developmentMode: Boolean, val configuration: KuicksilverApplicationEngine.Configuration, applicationProvider: () -> Application) : BaseApplicationEngine(source)

The Kuicksilver server engine (docs/guide/ktor.md): HTTP/1.1 over TLS on TCP through the CIO connection pipeline of Ktor (HTTP/2 there too when http2 is set), and HTTP/3 on UDP on the same port. Start it with embeddedServer(Kuicksilver, ...).

http3Advertising
Link copied to clipboard
var http3Advertising: Http3Advertising

Whether HTTP/3 is advertised and new HTTP/3 connections accepted, switched at runtime (docs/guide/ktor.md, "Turning HTTP/3 off on the server"); Http3Advertising.On until set. Every response reads it as its head goes out (so the next response on a keep-alive connection already follows a change), and every new client Initial when the QUIC endpoint admits it. Setting Http3Advertising.Drain sends GOAWAY to every live HTTP/3 connection in the background and returns at once; a connection accepted while it is set gets GOAWAY too. GOAWAY cannot be taken back: going back to Http3Advertising.On or Http3Advertising.Clear lets new connections in, while the drained ones finish their requests and close. Safe to set from any thread, before or after the start.

http3Stats
Link copied to clipboard
val http3Stats: List<EndpointStats>

The statistics of every HTTP/3 listener's QUIC endpoint (Http3Endpoint.stats: datagrams, drops, admission and limit refusals, handshakes; docs/guide/quic.md, "Observability"), one per TLS connector serving HTTP/3, in the order of the connectors. Empty before the start completes and when no connector serves HTTP/3; after a stop the endpoints' final counts. Each read takes a new snapshot; safe from any thread.
