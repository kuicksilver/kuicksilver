EngineMain

object EngineMain(source)

EngineMain for the Kuicksilver engine, configured like Ktor's own engines (ktor.deployment.*, and on the JVM ktor.security.ssl.* with -sslPort). Keys of its own, on every platform: kuicksilver.tls.certificateChain and kuicksilver.tls.privateKey (PEM files: the deployment port then serves TLS and HTTP/3), kuicksilver.tls.clientAuth (none, optional or required: ask for a client certificate) and kuicksilver.tls.clientCa (the PEM file of the CAs client certificates are verified against), kuicksilver.tls.versions (tls13, the default, or tls12And13: TLS 1.2 clients served too, under the RFC 9325 profile), kuicksilver.tls.keyExchangeGroups (a list of KeyExchangeGroups names, the server's order of preference, e.g. ["X25519MLKEM768", "x25519", "secp256r1"], or one string of them separated by : or ,; the default list when absent), kuicksilver.tls.ocspStapling (a DER OCSP response file stapled on TCP and QUIC, read again every kuicksilver.tls.reloadInterval; whether it is stapled is logged at startup and when that changes), kuicksilver.tls.trustedGateway (true: every client of the deployment port, TLS or cleartext behind a TLS-terminating proxy, is a trusted gateway: no 421 Misdirected Request), kuicksilver.tls.reloadInterval (how often those files are checked for a renewed certificate or CA bundle, e.g. 1h; off by default), kuicksilver.http3, kuicksilver.http2 (off by default), kuicksilver.h2c (off, the default, withHttp11 or only: HTTP/2 over cleartext TCP with prior knowledge on the plain deployment port, H2cMode; only without the kuicksilver.tls.* identity files), kuicksilver.http2RepeatOffenderPenalty (a duration; off by default), kuicksilver.maxTcpConnections, kuicksilver.maxTcpConnectionsPerIp (0 or absent is off), kuicksilver.quicMaxConnections, kuicksilver.quicMaxConnectionsPerIp (0 is off), kuicksilver.quicAcceptQueue, kuicksilver.altSvc, kuicksilver.webSocketsOverHttp3, kuicksilver.webSocketsOverHttp2 (on by default), kuicksilver.udpSocketCount (endpoint loops on the UDP port, every platform with a QUIC server), kuicksilver.proxyProtocol.trustedSources, headerTimeout and maxHeaderSize (the PROXY protocol on the deployment port, ProxyProtocolConfig; off by default).
