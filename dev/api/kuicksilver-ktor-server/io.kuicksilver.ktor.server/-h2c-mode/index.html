H2cMode

enum H2cMode : Enum<H2cMode> (source)

HTTP/2 over cleartext TCP ("h2c", RFC 9113 section 3.3: prior knowledge, no ALPN, no TLS) on a plain connector (KuicksilverPlainConnector.Builder.h2c, kuicksilver.h2c in EngineMain): for a server behind a TLS-terminating proxy or load balancer, inside a service mesh whose sidecar does the TLS, and for gRPC between services (ADR-0018).

Cleartext: nothing authenticates the client nor protects the bytes (CWE-319). Serve h2c only where the network between the two ends is trusted or protected by other means (a loopback hop, a private network, a sidecar's mTLS); docs/guide/ktor.md, "h2c". Upgrade: h2c (RFC 7540 section 3.2) is never taken: RFC 9113 section 3.1 deprecates it, and an HTTP/1.1 request that offers it is served as HTTP/1.1 (WithHttp11) as any request with an Upgrade the server does not take (RFC 9110 section 7.8). Every HTTP/2 limit, deadline and flood defence of a TLS connector holds on h2c unchanged.

WithHttp11

WithHttp11

HTTP/1.1 and h2c on the same port: a connection whose first 24 octets are the HTTP/2 client connection preface (PRI * HTTP/2.0\r\n\r\nSM\r\n\r\n, RFC 9113 section 3.4) is HTTP/2, any other HTTP/1.1. The octets are looked at as they arrive and none is consumed: the first one that differs from the preface hands the connection to HTTP/1.1 at once (a request shorter than the preface is never held back), and the wait for them is part of the first request head's deadline (requestHeaderTimeoutSeconds), as on HTTP/1.1. Go's golang.org/x/net/http2/h2c handler and Netty's CleartextHttp2ServerUpgradeHandler serve both on one port too. When the server stops during the wait, a connection that sent nothing yet is closed at once; one that sent the start of the preface is still waited for, within the same deadline (and the stop's grace period), as a request head that started on HTTP/1.1 is: a whole preface is HTTP/2, which serves the requests that came with it and ends with the graceful GOAWAY (RFC 9113 section 6.8), and the first octet that differs hands the connection to HTTP/1.1, which answers that request with Connection: close. A client that stops part way is closed at the deadline (as HTTP/1.1, so with 408).
