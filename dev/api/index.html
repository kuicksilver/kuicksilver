HTTP/3 (RFC 9114) with QPACK (RFC 9204) over kuicksilver-quic: requests and responses, extensible priorities (RFC 9218), Extended CONNECT (RFC 9220), HTTP datagrams and capsules (RFC 9297) and WebTransport sessions. Guide: docs/guide/http3.md.

The Ktor client engine HttpClient(Kuicksilver): HTTP/3, and HTTP/2 or HTTP/1.1 over TLS, with Alt-Svc and HTTPS record discovery, racing and fallback. Guide: docs/guide/ktor.md.

TLS for ktor-network sockets: Socket.tls() on the client and Socket.tlsServer() on the server, plus the WebSocket permessage-deflate extension the Ktor engines use. Guide: docs/guide/tls.md.

kuicksilver-ktor-server
Link copied to clipboard

The Ktor server engine embeddedServer(Kuicksilver): HTTP/1.1 (and HTTP/2 on request) over TLS on TCP and HTTP/3 on UDP on the same port, with Alt-Svc advertising. Guides: docs/guide/ktor.md, docs/guide/deployment.md.

kuicksilver-native
Link copied to clipboard

The ksl C shim with OpenSSL 3.5 statically linked inside, its JNI and cinterop bindings, the native library loader and the opt-in annotations shared by every Kuicksilver module. Applications rarely use it directly: the other modules call it. KslLoader.availability tells whether the native library could be loaded on this platform.

kuicksilver-quic
Link copied to clipboard

QUIC v1 and v2 (RFC 9000, 9001, 9002, 9369) for Kotlin Multiplatform: endpoints, connections, streams, datagrams (RFC 9221), connection migration and path MTU discovery, as a coroutine API over a sans-IO core. Guide: docs/guide/quic.md.

TLS 1.3 (and TLS 1.2 on request) over OpenSSL 3.5: configuration, certificate trust (the platform verifier, a private CA, SPKI pins, trust on first use), server identities, and TLS over any pair of byte channels. Guide: docs/guide/tls.md.
