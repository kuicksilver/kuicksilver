QuicTlsSession

@SubclassOptInRequired(markerClass = [ExperimentalKuicksilverApi::class])
interface QuicTlsSession : AutoCloseable(source)

The TLS handshake of one QUIC connection, driven by the transport without any I/O of its own (RFC 9001 section 4).

A call in the wrong state throws IllegalStateException; an error reported by TLS itself throws TlsException (most failures arrive as DriveResult.Failed instead). The native layer's exceptions never escape.

pendingCryptoBytes
Link copied to clipboard
open fun pendingCryptoBytes(level: EncryptionLevel): Int

CRYPTO bytes provided at level that TLS has not read yet. The transport counts them toward the memory of an unfinished handshake and, once TLS reads a higher level, treats any left at a lower one as a PROTOCOL_VIOLATION (RFC 9001 section 4.1.3). TLS holds at most 256 KiB unread per level: provide beyond that, or at a level below the one TLS reads, throws TlsException. Zero for a closed or failed session.

Client: resume ticket (it is consumed and closed by this session); call before the first drive. resumeSni
Link copied to clipboard
open fun resumeSni(selection: SniSelection)

Resumes a handshake paused at DriveResult.WantSni with selection from this session's selectSni, then call drive: the chosen identity's chain, key and settings take over this handshake; no override goes on with the default identity, or ends the handshake with the selection's alert (the next drive returns DriveResult.Failed). Takes selection over and closes it, also when it throws: IllegalStateException when no selection is pending or the session is closed, IllegalArgumentException for a selection another session made.

Resumes a handshake paused at DriveResult.WantVerify with the verdict, usually from verifyPeer; then call drive. A VerifyResult.Rejected makes TLS send its alert and the next drive return DriveResult.Failed. Throws IllegalStateException when no verification is pending.

selectSni
Link copied to clipboard
open suspend fun selectSni(clientHello: ClientHelloInfo): SniSelection

Server, for a DriveResult.WantSni: asks TlsConfig.sniSelector about clientHello and builds the configuration of the identity it chose. Safe to call off the connection loop: it reads the configuration only, never the handshake. Never throws for the selector's sake: an exception from it, or an override that does not suit QUIC, becomes a selection that ends the handshake with internal_error. Pass the result to resumeSni, or close it. IllegalStateException when the configuration has no sniSelector, and from the default: a session that never answers DriveResult.WantSni has nothing to select.

abstract fun setQuicVersion(version: Int)

The QUIC version whose labels derive the Handshake and 1-RTT keys (RFC 9369 section 3.3). A client sets its Original Version before the first drive and the server's version (from its Initial header) before providing the ServerHello; a server lets ksl choose per RFC 9368. Unknown version: IllegalArgumentException; once Handshake keys exist: IllegalStateException.
