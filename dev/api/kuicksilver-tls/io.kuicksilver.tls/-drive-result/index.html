WantSni
Link copied to clipboard
class WantSni(val clientHello: ClientHelloInfo) : DriveResult

Server: the handshake is paused at the ClientHello for TlsConfig.sniSelector. Run QuicTlsSession.selectSni with clientHello off the connection loop (the selector may suspend), pass its result to QuicTlsSession.resumeSni on the loop, then call QuicTlsSession.drive. Until then QuicTlsSession.drive answers this again; CRYPTO data may still be provided.
