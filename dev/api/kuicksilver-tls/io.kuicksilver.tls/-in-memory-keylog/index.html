InMemoryKeylog

class InMemoryKeylog : KeylogSink(source)

A KeylogSink that keeps the lines in memory, for tests and diagnostics. Not synchronized: give each concurrently running connection its own instance. The lines are secrets; never keep one in production.

open override fun log(line: String)

Receives one line without its newline, e.g. CLIENT_HANDSHAKE_TRAFFIC_SECRET <client random> <secret>. It is called inside the handshake, possibly from several connections at once, so it must be quick, thread-safe and must not throw: an exception propagates into the handshake.
