val base: TrustConfig

the trust that must accept the chain as well (AND, never OR: ADR-0011); default Platform. Tofu, Custom (also inside ExpectedName) and another Pinned throw TlsException.Config: a Custom verifier decides on its own, so pins on top of it would only look like a second check.

pins
Link copied to clipboard
val pins: Set<SpkiSha256>

The accepted SPKI hashes (RFC 7469), never empty; one match is enough, so list a backup key to survive a key rotation. A miss fails with VerifyReason.PinMismatch even when base trusts the chain.
