LoadBalancerKey

@SubclassOptInRequired(markerClass = [ExperimentalKuicksilverApi::class])
interface LoadBalancerKey : AutoCloseable(source)

An AES-128 block key for QUIC-LB connection IDs (draft-ietf-quic-load-balancers-21 section 5.4, experimental): the material lives inside the native layer (ADR-0003). One block per call; safe to call from several threads at once.
