Certificate

class Certificate(der: ByteArray)(source)

An X.509 certificate in DER form with the few fields the TLS layer needs; parsing is lazy and failures surface as TlsException.Config. A validity time the minimal walker cannot read (OpenSSL also accepts a fractional GeneralizedTime or a UTCTime offset) fails only the validity bounds, never the names.
