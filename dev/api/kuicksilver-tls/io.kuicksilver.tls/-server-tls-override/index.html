alpn
Link copied to clipboard
val alpn: List<String>?

replaces TlsConfig.alpn for this connection; null keeps it. Over TCP the list goes without h3, which identifies HTTP/3 over QUIC only (RFC 9114 section 3.1): one of h3 alone ends a TCP handshake with no_application_protocol (RFC 7301 section 3.2), the name being served over QUIC only, as for TlsConfig.alpn.

keyExchangeGroups
Link copied to clipboard
var keyExchangeGroups: KeyExchangeGroups?

The key-exchange groups the server picks from on this connection (its own order decides, RFC 9846 section 4.3.7); null keeps TlsConfig.keyExchangeGroups. Applied once the selector answered, so a ClientHello without a key share for them gets a HelloRetryRequest for this list's group, as under TlsConfig.keyExchangeGroups. An override with key shares (a client's setting) aborts the handshake with TlsException.Config, as TlsConfig.Builder.build refuses them.

ocspStapling
Link copied to clipboard
var ocspStapling: OcspStapling?

The OCSP response stapled for identity on this connection (RFC 6066 section 8); null staples nothing, never the response of TlsConfig.ocspStapling, which is for the default identity. See OcspStapling.

trust
Link copied to clipboard
val trust: TrustConfig?

replaces TlsConfig.trust for client certificates on this connection; null keeps it. The override passes the checks of TlsConfig.Builder.build: with client certificates the trust must be AnchoredCa or ReloadableCa (optionally inside Pinned) and ALPN entries are counted in bytes; a failing override aborts that connection's handshake with TlsException.Config.
