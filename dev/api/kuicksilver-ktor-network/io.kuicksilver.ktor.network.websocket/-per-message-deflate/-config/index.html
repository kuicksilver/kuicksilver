fun compressIf(predicate: (Frame) -> Boolean)

Compresses a message only when predicate (and every earlier one) agrees, decided on its first frame. For messages that put a secret next to data an attacker can choose: compressed in one window, their size can tell the secret (CRIME, BREACH; RFC 7692 section 8); sent uncompressed, they do not share it.
