Http3Exception

sealed class Http3Exception : IOException, CopyableThrowable<Http3Exception> (source)

Errors of the HTTP/3 layer (RFC 9114 section 8). Transport failures stay QuicException; fromQuic reads an HTTP/3 meaning out of an application close or a stream reset. Cancellation is never wrapped.

class FieldSectionTooLarge(val streamId: Long, val limit: Long) : Http3Exception

A field section (headers or trailers) above maxFieldSectionSize once decoded; the stream was stopped with H3_EXCESSIVE_LOAD. Also thrown locally, before anything is sent, for a section above the peer's SETTINGS_MAX_FIELD_SECTION_SIZE: a request is refused before its stream is opened, a response by respond (the stream is reset with H3_INTERNAL_ERROR), request trailers by resetting the stream with H3_REQUEST_CANCELLED in both directions and failing request, or the response body and trailers when the response already began, with this exception.
