packetTooBig
Link copied to clipboard
val packetTooBig: Boolean

send an ICMP Packet Too Big to a target whose UDP payload is dropped because it does not fit the client's QUIC DATAGRAM frames (RFC 9298 section 6.1), when the process may open a raw ICMP socket (Linux and Android with CAP_NET_RAW); without that privilege, or with false, the payload is only dropped and counted. True by default; UdpProxyStats.packetTooBig says which applies. At most 10 a second per target address (a burst of 5) and 100 a second over the proxy, never more than the payloads dropped. Sent from the address the target sent to: see socketFactory.

refuseOwnAddresses
Link copied to clipboard
val refuseOwnAddresses: Boolean

refuse the proxy's own addresses as targets, 403 with destination_ip_prohibited before a socket exists: the address the request's connection reached and the listener's when it is bound to one, an IPv4-mapped, NAT64 (64:ff9b::/96) or 6to4 (2002::/16) target compared by the IPv4 address it carries. RFC 9298 section 7: a proxy that does not disallow "the UDP proxy's own addresses" lets clients reach services listening on the proxy host itself, which a firewall in front of it does not see. On by default, applied whatever targetFilter allows; set false only where a target on the proxy's own host is meant (a test, a sidecar). Other addresses of the host (NAT aliases, other interfaces), which the library does not list, go to UdpTargetFilter.excluding.

socketFactory

val socketFactory: suspend (InetSocketAddress) -> DatagramIo

opens the UDP socket of a tunnel on a wildcard address of the target's family (0.0.0.0:0 or [::]:0); DatagramIo.open by default, the accelerated socket where it exists, which sets Don't Fragment and, on the wildcard bind, reports each datagram's destination, the source of a packetTooBig message. A factory may bind one address instead (its Packet Too Big messages leave from it); a wildcard socket that does not report destinations (the portable one) sends none, counted in UdpProxyStats.packetTooBigNoSource.
