AllowAll

val AllowAll: UdpTargetFilter

Every target: loopback, the proxy's own network, broadcast. Only for a proxy whose clients are as trusted as the host it runs on (a test, a lab): with it any client reaches whatever listens on UDP there (CWE-918).

PublicOnly
Link copied to clipboard
val PublicOnly: UdpTargetFilter

Globally reachable unicast only, the default (section 7: "the UDP proxy disallows UDP proxying requests to vulnerable targets, such as the UDP proxy's own addresses and localhost, link-local, multicast, and broadcast addresses"): loopback, unspecified, private (RFC 1918, ULA), shared (RFC 6598), link-local, multicast, the limited broadcast address, documentation and benchmarking ranges and the rest of the IANA Special-Purpose Address Registries that is not globally reachable are refused; an IPv4-mapped, NAT64 or 6to4 address is judged by its IPv4 address. A proxy that has public addresses of its own adds them with excluding.
