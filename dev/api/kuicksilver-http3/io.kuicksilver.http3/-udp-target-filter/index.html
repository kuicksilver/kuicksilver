UdpTargetFilter

fun interface UdpTargetFilter(source)

Which targets a UdpProxy sends to (RFC 9298 section 7). It sees each address the target resolved to (4 or 16 bytes), the host the client named (a literal or a DNS name) and the port; the proxy uses the first address it allows and answers 403 with proxy-status: ...; error=destination_ip_prohibited when it allows none. The check runs on resolved addresses, and the proxy sends to the very address it allowed, so a DNS answer cannot steer it elsewhere afterwards.
