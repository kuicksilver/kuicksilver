Http3Response

interface Http3Response(source)

The final response to an Http3Request. Reading body to the end completes trailers (null without trailers).

Properties

body
Link copied to clipboard
abstract val body: ByteReadChannel

The response content from DATA frames; it ends at the server's FIN (and trailers, if any). A body cut short — a reset, a lost connection, a failed request — fails every read with its cause (Http3Exception or the connection's io.kuicksilver.quic.QuicException.ConnectionLost) and is never isClosedForRead, so it cannot pass for complete.

abstract fun cancel(code: Long = Http3ErrorCode.REQUEST_CANCELLED)

Abandons the response: STOP_SENDING (and RESET_STREAM if the request body is still being sent) with code. H3_REQUEST_REJECTED, which clients MUST NOT use (RFC 9114 section 4.1.1), goes out as H3_REQUEST_CANCELLED.
