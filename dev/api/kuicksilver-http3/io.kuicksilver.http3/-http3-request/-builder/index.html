Builder

class Builder(var method: String, var authority: String?, var path: String?)(source)

Builds an Http3Request: method, authority and path as the pseudo-headers, everything else optional; see the properties of Http3Request for what each setting means. New options arrive as new properties here, so code that builds requests keeps compiling and linking.
