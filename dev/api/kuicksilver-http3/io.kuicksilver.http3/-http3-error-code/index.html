Http3ErrorCode

object Http3ErrorCode(source)

HTTP/3, QPACK and WebTransport application error codes (RFC 9114 section 8.1, RFC 9204 section 6, RFC 9297 section 5.2, draft-ietf-webtrans-http3-16 section 9.5). They travel in CONNECTION_CLOSE 0x1d, RESET_STREAM and STOP_SENDING; an unknown code means NO_ERROR (RFC 9114 section 9).
