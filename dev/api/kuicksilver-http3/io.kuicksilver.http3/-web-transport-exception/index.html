ConnectionFull
Link copied to clipboard
class ConnectionFull(message: String) : WebTransportException

Client: the connection cannot take one more session: it has one and no WebTransport flow control (section 5.1: "If flow control is not enabled, clients MUST NOT attempt to establish more than one simultaneous WebTransport session"), or it carries Http3Settings.webTransportMaxSessions already. Nothing was sent; another connection to the same server can take it.

FlowControl
Link copied to clipboard
class FlowControl(message: String) : WebTransportException

The session broke WebTransport flow control (draft-ietf-webtrans-http3-16 section 5): the peer opened more streams or sent more data than our limits allowed, or sent a flow-control capsule that lowered a limit or went beyond 2^60 streams, or a WT_MAX_STREAM_DATA or WT_STREAM_DATA_BLOCKED capsule. The session was closed by resetting its CONNECT stream with WT_FLOW_CONTROL_ERROR. A session the peer closed that way ends with the peer's reset as the cause instead.
