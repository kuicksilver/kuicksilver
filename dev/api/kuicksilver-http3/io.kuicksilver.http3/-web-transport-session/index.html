WebTransportSession

interface WebTransportSession(source)

A WebTransport session over HTTP/3 (draft-ietf-webtrans-http3-16): an Extended CONNECT stream that groups WebTransport streams and datagrams. With WebTransport flow control (section 5, on when both sides declare it in their SETTINGS) its streams and stream data stay within the peer's limits and a violation by the peer closes the session (WebTransportException.FlowControl); without it a connection carries one session (section 5.1).

The session ends with close on either side (WT_CLOSE_SESSION with a code and a reason, then FIN), with the peer's FIN on the CONNECT stream (code 0), or with a failure (a malformed capsule, a reset CONNECT stream, a lost connection); closed says which. Its streams are then reset and stopped with WT_SESSION_GONE, opening and accepting throw WebTransportException.SessionClosed, and the connection's session slot is free once both directions of the CONNECT stream ended. Application error codes, of the session and of its streams, are 0..2^32-1 (section 4.4).

close
Link copied to clipboard
abstract suspend fun close(code: Long = 0, reason: String = "")

Closes the session (section 6): WT_CLOSE_SESSION with code (0..2^32-1) and reason (cut to 1024 bytes of UTF-8 at a character boundary), then FIN; the session's streams are reset with WT_SESSION_GONE. Returns once the peer's FIN answered, which ends the CONNECT stream both ways; a peer that does not answer within five seconds is stopped with STOP_SENDING WT_SESSION_GONE. Writing the capsule waits at most five seconds for the peer's flow-control credit, after which the CONNECT stream is reset instead. Cancelling the call stops only its wait. Calling it on a closed session does nothing.
