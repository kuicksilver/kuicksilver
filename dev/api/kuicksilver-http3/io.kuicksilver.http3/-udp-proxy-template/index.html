UdpProxyTemplate

class UdpProxyTemplate(source)

The URI Template a client is configured with to reach a UDP proxy (RFC 9298 section 2), such as https://proxy.example:4443/masque{?target_host,target_port}. parse checks every requirement of section 2 and refuses the template otherwise ("the client MUST reject its configuration and abort the request without sending it").
