CapsuleConfig

class CapsuleConfig(val knownTypes: Set<Long> = emptySet(), val maxCapsuleLength: Int, val maxDatagramLength: Int, val datagramFallback: Boolean = true, val receiveQueue: Int = 16, val sendQueue: Int = 32, val terminalTypes: Set<Long> = emptySet())(source)

How an Extended CONNECT stream speaks the Capsule Protocol (Http3Stream.useCapsuleProtocol); build it with the constructor, capsuleConfig or Builder.

Memory per stream is bounded by receiveQueue * maxCapsuleLength for received capsules, 32 datagrams of at most maxDatagramLength bytes, and sendQueue capsules of the application's own size: unknown and oversized DATAGRAM capsules are skipped as their bytes arrive, never buffered.

datagramFallback
Link copied to clipboard
val datagramFallback: Boolean

send a datagram as a DATAGRAM capsule when HTTP/3 datagrams are unsupported on the connection (either side's SETTINGS_H3_DATAGRAM is 0); true by default. A datagram too large for a QUIC DATAGRAM frame is never turned into a capsule. Until the peer's SETTINGS arrive, HTTP/3 datagrams count as unsupported (PeerDoesNotSupport), though the peer may still turn them on: with the fallback such datagrams go as capsules, without it they are refused. A client's connect returns only after the server's SETTINGS, so only a server that accepts a CONNECT before the client's SETTINGS arrived sees this.

val knownTypes: Set<Long>

capsule types delivered in CapsuleStream.capsules; any other type is skipped silently (RFC 9297 section 3.2), except DATAGRAM, which always goes to CapsuleStream.datagrams. Each in 0..2^62-1; empty by default.

terminalTypes
Link copied to clipboard
val terminalTypes: Set<Long>

types of knownTypes whose capsule ends the stream's data: it is delivered, and any byte after it (a capsule of any type, even one that would be skipped) is a malformed message, so the stream is reset with H3_MESSAGE_ERROR and CapsuleStream.capsules fails with Http3Exception.MessageError. For WebTransport's WT_CLOSE_SESSION (draft-ietf-webtrans-http3 section 6). Each must be in knownTypes and not DATAGRAM; empty by default.
