Http3Endpoint

class Http3Endpoint : AutoCloseable(source)

HTTP/3 over a bound QUIC endpoint: the transport surface the Ktor engines use (layer rule, ADR-0005). TLS configurations must offer ALPN h3 (RFC 9114 section 3.1); an accepted connection that negotiated anything else is closed, and connect/connectEarly fail with H3_GENERAL_PROTOCOL_ERROR (Http3Exception.Protocol) when the server chose another protocol the client offered. SETTINGS_H3_DATAGRAM follows the transport: it is 1 only when QuicConfig.maxDatagramFrameSize is not 0. QuicConfig.maxUniStreams must be at least 3, so the peer can open its control and QPACK streams (RFC 9114 section 6.2): bind, connect and connectEarly throw IllegalArgumentException for a smaller value. With Http3Settings.webTransport is turned on (WebTransport needs reset_stream_at on both sides, draft-ietf-webtrans-http3-16 section 3.1), as the Ktor engines do.

connect
Link copied to clipboard
suspend fun connect(remote: InetSocketAddress, tls: TlsConfig, quic: QuicConfig = QuicConfig.Default, settings: Http3Settings = Http3Settings.Default): Http3Connection

Opens a client connection to remote; the handshake and our SETTINGS are done when this returns, unless the server sent GOAWAY first (it is stopping): the connection is then returned with Http3Connection.goAwayReceived set and already closing, and a request on it fails with Http3Exception.RequestNotProcessed (retry-safe, RFC 9114 section 5.2). Any other connection error that ends HTTP/3 before this returns (for example a malformed control stream from the server) is thrown as Http3Exception, and the QUIC connection is closed.

connectEarly
Link copied to clipboard
suspend fun connectEarly(remote: InetSocketAddress, tls: TlsConfig, quic: QuicConfig = QuicConfig.Default, settings: Http3Settings = Http3Settings.Default, earlyData: EarlyDataState = EarlyDataState.Allowed): Http3Connection

As connect with 0-RTT (ADR-0015): resumes a ticket this endpoint kept from an earlier connection to the same server and returns as soon as 0-RTT keys exist. Requests with allowEarlyData (safe methods without a body) then go out in 0-RTT; every other request waits for the handshake. earlyData must not be EarlyDataState.Disabled. Early requests can be replayed by an attacker (RFC 9846 section 8). A connection error that ends HTTP/3 before this returns is thrown as Http3Exception, like connect's; with 0-RTT accepted that includes H3_SETTINGS_ERROR when the server's SETTINGS are not compatible with the ones stored with the ticket (RFC 9114 section 7.2.4.2).

shutdown
Link copied to clipboard
suspend fun shutdown(grace: Duration, code: Long = Http3ErrorCode.NO_ERROR, reason: String = "shutdown")

Graceful shutdown of the QUIC endpoint (QuicEndpoint.shutdown): new clients are refused at once, live connections get grace to finish, then the rest close with code (H3_NO_ERROR by default). Send GOAWAY on every live connection (Http3Connection.goAway) first or meanwhile, so clients stop sending new requests and finish the ones in flight.
