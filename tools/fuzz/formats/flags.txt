# The flag bits, setup bits and outcomes of the traced connection programs, each by its constant and by the name its trace
# gives it (the trace is hashed into tools/fuzz/formats/<target>.lock, so a renamed flag changes the recorded decoding of
# every input that sets it). `program <name> <source> <targets>` declares a program; `<program> <field> <value> <CONSTANT>
# <trace name>` is one bit (flags, setup) or outcome. The trace name is the constant's name in lowerCamelCase, bits are 1,
# 2, 4, ... and outcomes 0, 1, 2, ... without a gap. Checked against the sources by tools/check/fuzz-formats.py and against
# the compiled programs by FuzzTraceTest; a row changed or removed on a branch needs a line in changes.txt naming every
# target of its program.
