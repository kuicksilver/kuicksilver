Kuicksilver WebTransport check

Runs each step against this server's /wt/echo and /wt/server-close routes, then the error code stage against /wt/codes, /wt/close-probe and /wt/server-close-32 (WtCodesProbe), and posts the code table to /codes and the result to /result. With ?hash=<base64 SHA-256 of the certificate> the sessions use serverCertificateHashes (a certificate valid for at most 14 days, not RSA).
