# RFC 9113 — HTTP/2

Details of the rows of the [RFC compliance summary](../rfc-compliance.md) for this document. Each section gives the requirement, how Kuicksilver meets it (with the files), the tests that pin it, its history, notes on peers and the open items. Status: ✅ met · 🔶 feature subset · ⬜ planned · ❌ not planned; "since" is the release from which the current behaviour holds (history below and in [CHANGELOG.md](../../../CHANGELOG.md)).

## <a id="http-2"></a>HTTP/2

Status: 🔶 since 0.3.0 · [summary](../rfc-compliance.md#http)

Original row: RFC 9113.

**Requirement.** HTTP/2.

**Recorded status.** 🔶 0.3.0 (in progress)

**How it is met.**

- ADR-0017: a new module `kuicksilver-http2` next to `kuicksilver-http3`, a sans-IO core (`frame`, `hpack`, `core`)
  checked by `:kuicksilver-http2:checkHttp2Architecture`; HTTP/2 only after ALPN `h2` over TLS (no h2c, sections 3.2
  and 3.3 make it optional), no server push.

**History.**

- 0.2.x: ❌ by decision (ADR-0009, "No HTTP/2 in v1"), superseded by ADR-0017 on 2026-11-04.

**Open items.**

- The Ktor client and server engines (ALPN `h2`, the connection pool, the request and response mapping of section 8),
  RFC 8441 and the h2spec run of the release gate.
