## <a id="s1-2-2-delta-seconds"></a>§1.2.2 — delta-seconds in Alt-Svc `ma`

Status: ✅ since 0.2.1 · [summary](../rfc-compliance.md#http)

**Requirement.** A delta-seconds value too large to represent is taken as 2147483648 (§1.2.2, a MUST addressed to a cache, which the Alt-Svc cache follows).

**How it is met.** Recorded in the row [RFC 7838 §3, §3.1 (Alt-Svc on HTTP/3 responses, quoted-string, `ma`)](7838.md#s3-alt-svc-on-http-3-responses):

- `ma` is delta-seconds (`1*DIGIT`, a sign makes the alternative invalid), and one too large to represent counts as 2147483648 (§3.1 takes delta-seconds from RFC 9111 §1.2.2, whose MUST is addressed to a cache; the Alt-Svc cache follows it; 0.2.1 review, before the alternative was dropped)
