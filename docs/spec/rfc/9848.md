## <a id="ech-https-records"></a>The `ech` parameter of HTTPS records

Status: ⬜ planned for 0.3.0 · [summary](../rfc-compliance.md#http)

Original row: RFC 9848.

**Requirement.** The `ech` SvcParam of SVCB and HTTPS records carries the server's ECH configuration list, and a client
that uses it follows the rules of the RFC for its connections (including the SVCB-reliant behaviour).

**Recorded status.** ⬜ planned for 0.3.0 (owner decision of 2026-11-18, [ADR-0019](../../adr/0019-openssl-4-and-ech.md)).

**How it is met.**

- Not yet. The Ktor client reads HTTPS records already ([RFC 9460](9460.md)); the `ech` parameter feeds the ECH of
  [RFC 9849](9849.md#ech) once that is in place.

**Open items.**

- Everything above, for QUIC and for TLS over TCP alike.
