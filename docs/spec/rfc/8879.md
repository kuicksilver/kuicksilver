## <a id="certificate-compression"></a>certificate compression

Status: ⬜ planned for 0.3.0 · [summary](../rfc-compliance.md#tls)

Original row: RFC 8879.

**Requirement.** Certificate compression.

**Recorded status.** ⬜ planned for 0.3.0, through OpenSSL 3.5 (owner decision of 2026-11-16, which reverses "not planned for 0.x": a compressed certificate chain keeps a server's first flight within QUIC's amplification limit, RFC 9000 §8.1); [roadmap](../../roadmap.md#feature-parity-decided-2026-11-16)

**Prerequisite.** RFC 8879 compresses the certificate chain with an algorithm both sides support (zlib, brotli or zstd).
The bundled OpenSSL is built `no-comp` and with none of the three libraries (`tools/openssl/configure-flags.txt`), so
OpenSSL offers no certificate compression. The item starts with the decision which library to bundle, its pin, signature
check and SBOM entry like OpenSSL's, and dropping `no-comp`.
