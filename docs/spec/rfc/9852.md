## <a id="tls-1-3-as-every-protocols"></a>(BCP 195) — TLS 1.3 as every protocol's default

Status: ✅ since 0.2.0 · [summary](../rfc-compliance.md#tls)

Original row: RFC 9852 (BCP 195).

**Requirement.** TLS 1.3 as every protocol's default.

**Recorded status.** ✅ 0.2.0

**How it is met.**

- RFC 9325 §3.1.1 for TLS: 1.3 MUST, 1.2 MAY
- `TlsVersions.Tls13` is the default and QUIC accepts nothing else
- TLS 1.2 only over TCP with `TlsVersions.Tls12And13`
- the Ktor server connector offers 1.3 only
- the client configures the version range, OpenSSL 3.5's highest version is 1.3

**Tests that pin it.**

- C `tcp_default_versions_and_tls12_profile` (a new context is TLS 1.3 only), `TlsConfigTest.quicRequiresTls13Only`
