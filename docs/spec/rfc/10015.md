## <a id="tls-1-2-key-exchange"></a>TLS 1.2 key exchange

Status: ✅ since 0.3.0 · [summary](../rfc-compliance.md#tls)

Original row: RFC 10015.

**Requirement.** TLS 1.2: no static RSA key transport, no FFDH or FFDHE (MUST NOT), no static ECDH (SHOULD NOT).

**Recorded status.** ✅ 0.2.0

**How it is met.**

- the TLS 1.2 list is six ECDHE suites with RSA or ECDSA signatures and AEAD
- OpenSSL 3 has no fixed-DH client certificate types
- C `tcp_default_versions_and_tls12_profile` (every TLS 1.2 suite is ECDHE + AEAD)

**History.**

- 0.3.0: `ksl_ctx_set_ciphers` refuses a TLS 1.2 list with any other suite at the C level too
