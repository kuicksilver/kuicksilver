## <a id="hostname-verification"></a>(obsoletes RFC 6125) — hostname verification

Status: ✅ since 0.2.0 · [summary](../rfc-compliance.md#tls)

Original row: RFC 9525 (obsoletes RFC 6125).

**Requirement.** Hostname verification.

**Recorded status.** ✅ 0.2.0 (`VerificationNegativeTest`, C `test_quic.c` `test_no_verify_name`, `KslSmokeTest.forgottenVerifyNameFails`)

**How it is met.**

- a single matcher from `ksl` on all platforms
- DNS-ID and IP-ID
- no SRV-ID/URI-ID
- replaceable, cannot be disabled
