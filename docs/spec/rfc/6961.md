## <a id="status-request-v2"></a>`status_request_v2`

Status: ❌ · [summary](../rfc-compliance.md#tls)

**Why not.** RFC 9846 §4.5.1.1: "The status_request_v2 extension [RFC6961] is deprecated. TLS 1.3 servers MUST NOT act upon
its presence or information in it when processing ClientHello messages; in particular, they MUST NOT send the
status_request_v2 extension in the EncryptedExtensions, CertificateRequest, or Certificate messages." RFC 9325 §7.5: it "has
seen little deployment and had been deprecated by [RFC8446]. As a result, although this extension was recommended for TLS 1.2
in [RFC7525], it is no longer recommended by this document."

**How it stands.** Never sent by a client; a server ignores it (OpenSSL does not implement it) and staples through
`status_request` only ([RFC 6960 row](6960.md#ocsp-stapling)).
