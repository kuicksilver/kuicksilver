# RFC 7301 — TLS Application-Layer Protocol Negotiation Extension

Details of the rows of the [RFC compliance summary](../rfc-compliance.md) for this document. Each section gives the requirement, how Kuicksilver meets it (with the files), the tests that pin it, its history, notes on peers and the open items. Status: ✅ met · 🔶 feature subset · ⬜ planned · ❌ not planned; "since" is the release from which the current behaviour holds (history below and in [CHANGELOG.md](../../../CHANGELOG.md)).

## <a id="alpn"></a>RFC 9001 §8.1 — ALPN

Status: ✅ since 0.2.0 · [summary](../rfc-compliance.md#tls)

Original row: RFC 7301, RFC 9001 §8.1.

**Requirement.** ALPN.

**Recorded status.** ✅ 0.2.0

**How it is met.**

- mandatory for QUIC (an empty list is a configuration error), a mismatch closes the connection
- in QUIC a server refuses a ClientHello without the extension and a client a server that negotiated none, both with `no_application_protocol` (CRYPTO_ERROR 0x0178; OpenSSL alone checks only an offered list without overlap)

**Tests that pin it.**

- `TlsConfigTest.emptyAlpnInQuicIsConfigError`, `TlsConnectionTest.negative_alpnMismatchClosesConnection`, `QuicHandshakeTest.handshakeAnchoredCaAlpnH3`, C `quic_no_alpn_is_no_application_protocol`

## <a id="s3-1-protocol-name-lengths"></a>§3.1 — protocol name lengths

Status: ✅ since 0.2.0 · [summary](../rfc-compliance.md#tls)

Original row: RFC 7301 §3.1.

**Requirement.** Protocol names are 1..255 bytes (UTF-8), not characters.

**Recorded status.** ✅ 0.2.0

**How it is met.**

- the list fits ksl's 255-byte wire buffer
- a server's SNI override passes the same checks

**Tests that pin it.**

- `TlsConfigTest.negative_alpnLengthCountedInBytes`, `TlsConfigTest.negative_overrideClientAuthNeedsAnchoredCa`
