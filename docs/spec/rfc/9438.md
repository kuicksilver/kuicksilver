## <a id="cubic"></a>CUBIC

Status: ✅ since 0.2.0 · [summary](../rfc-compliance.md#quic)

Original row: RFC 9438.

**Requirement.** CUBIC.

**Recorded status.** ✅ 0.2.0

**How it is met.**

- `Cubic` by default (`QuicConfig.congestionController`, NewReno remains an option), arithmetic in bytes, C = 0.4, β = 0.7, fast convergence (§4.6: W_max = cwnd·(1+β)/2 on a loss below the previous W_max), target W_cubic(t + RTT) clamped to [cwnd, 1.5·cwnd] (§4.2) where t leaves out application-limited ACKs and time with nothing in flight (0.2.0; Linux shifts the epoch the same way), Reno-friendly region with α = 3(1−β)/(1+β) (§4.3) that becomes 1 once W_est reaches the window before the last reduction (0.2.0), minimum window of 2 datagrams on persistent congestion, ECN-CE as a congestion event, one reduction per recovery period
- HyStart++ (RFC 9406): a round ends with an ACK of a packet sent after the round started, every sample of a round counts toward its minimum and the checks run on each ACK from the 8th sample on (0.2.0), threshold max(4 ms, min(16 ms, lastMin/8)) → Conservative Slow Start (growth ÷ 4) with the entering round's minimum as baseline (0.2.0; it was the previous round's), 5 CSS rounds → exit from slow start, an RTT drop below the baseline → back to slow start
- RTT samples reach the controller through `CongestionController.onRttSample` (the default hook is empty)
- pacing and `sendQuantum` — as for NewReno

**Tests that pin it.**

- `recovery.CubicTest.*` (17: `initialWindowLikeNewReno`, `lossReducesToSeventyPercent`, `fastConvergenceLowersWmax`, `growthReachesWmaxAtK`, `renoFriendlyRegionOnShortRtt`, `appLimitedDoesNotGrow`, `persistentCongestionToMinimum`, `ecnCeIsCongestionEvent`, `noSecondReductionInsideRecovery`, `hystartEntersCssOnRttIncrease`, `hystartExitsAfterFiveCssRounds`, `hystartBackToSlowStartWhenRttDrops`, `idleTimeIsNotPartOfTheCubicEpoch`, `applicationLimitedTimeIsNotPartOfTheCubicEpoch`, `renoFriendlyAlphaBecomesOneAtThePriorWindow`, `hystartCssBaselineIsTheRoundThatEnteredIt`, `hystartEverySampleOfARoundCounts`), `QuicConfigTest.defaultControllerIsCubic`, `testing.SimulatorTest.cubicTransferWithLossFinishes` (10 MiB, 5 % loss, seed 1..5), Monte Carlo
