# Module kuicksilver-http3

HTTP/3 (RFC 9114) with QPACK (RFC 9204) over `kuicksilver-quic`: requests and responses, extensible priorities
(RFC 9218), Extended CONNECT (RFC 9220), HTTP datagrams and capsules (RFC 9297) and WebTransport sessions. Guide:
`docs/guide/http3.md`.

# Package io.kuicksilver.http3

`Http3Endpoint.bind` / `Http3Endpoint.connect`, `Http3Connection`, requests, streams, headers, settings, the
WebTransport API and `Http3Exception`.
