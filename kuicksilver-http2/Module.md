# Module kuicksilver-http2

HTTP/2 (RFC 9113) with HPACK (RFC 7541) as a sans-IO core over any byte stream; the Ktor engines use it for HTTP/2 over
TLS. Guide: `docs/guide/ktor.md`.

# Package io.kuicksilver.http2

`Http2Settings` and `Http2ErrorCode`.

# Package io.kuicksilver.http2.runtime

`Http2Exception`, the error an HTTP/2 connection or stream ends with.
